# Coffee Records — Frontend

React 19 + TypeScript SPA built with Vite and Mantine UI. In production it is compiled and embedded into the Flask container (see the root `README.md`). In development it runs as a separate Vite dev server that proxies `/api` requests to the Flask backend.

## Development

```bash
npm install
npm run dev       # Vite dev server on :5173, proxies /api to :5000
```

Flask must be running locally on port 5000 for API calls to work (see root README for backend setup). On the Docker host, port 5000 is the local registry: run Flask on another port (e.g. 5099) and point the `/api` and `/health` proxy targets in `vite.config.ts` at it, without committing that change.

## Checks

```bash
npx tsc -b --noEmit   # type-check
npx eslint .          # lint
npm test              # Vitest unit tests
```

## Build

```bash
npm run build     # compiles to dist/
```

The multi-stage `Dockerfile` at the project root runs this automatically. You do not need to build manually for deployment.

## Shot graphics

The Shots page keeps media inside the existing card header so coffee and telemetry graphics do not make rows taller:

- A 28×28 coffee-label thumbnail is shown when the shot's coffee has an uploaded photo. Clicking it opens the full image in a responsive modal.
- Telemetry-enabled shots show a compact generated chart preview. Clicking it opens the interactive telemetry chart, with the fitted pre-infusion, shot time and pressure profile below it (fetched from `GET /api/shots/:id/telemetry/phases`).
- If a telemetry preview is missing or fails to load, the chart action icon remains available as a fallback.

The shot API supplies `coffee_image_filename` and `telemetry_thumbnail_filename`. Resource URLs are built centrally in `src/api/resources.ts`; JSON and PNG telemetry resources are served from the `telemetry/` subdirectory.

Telemetry thumbnail images are generated by the Flask backend during upload, not by the browser. See the root README for validation, storage, backfill, and deployment instructions.
